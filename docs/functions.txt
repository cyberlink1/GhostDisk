================================================================================
                               functions.sh
                          FUNCTION DOCUMENTATION
================================================================================

This file contains a collection of utility routines used inside an initramfs
environment. They manage temporary files, block-device scanning, partition
selection, encrypted storage creation, and LUKS lifecycle operations.

Each section below describes the purpose, inputs, and outputs of the functions.
Nothing here mutates behavior; this file is a lantern for the labyrinth.

--------------------------------------------------------------------------------
 TEMP FILE & DIR REGISTRATION
--------------------------------------------------------------------------------

register_tmpfile <path>
    Adds a file path to the global TMPFILES list for cleanup.

register_tmpdir <path>
    Adds a directory path to the global TMPDIRS list for cleanup.

--------------------------------------------------------------------------------
 CLEANUP ROUTINES
--------------------------------------------------------------------------------

is_mounted <path>
    Checks whether the given path is an exact mountpoint in /proc/mounts.
    Exit code: 0 if mounted, 1 otherwise.

cleanup
    Removes registered temporary files.
    Removes registered temporary directories, but only if they are not mounted.

--------------------------------------------------------------------------------
 PARTITION ENUMERATION
--------------------------------------------------------------------------------

select_partition
    Scans /sys/block/* for real block devices and their partitions.
    Filters pseudo/virtual devices.
    For each partition:
        - Determines manufacturer
        - Computes size in MiB
        - Assigns a letter identifier (a, b, c...)
    Displays a 'dialog' menu and prints the selected /dev/<partition>.
    Returns: partition path via stdout.

--------------------------------------------------------------------------------
 MOUNTED PARTITIONS LIST
--------------------------------------------------------------------------------

mounted_partitions
    Outputs a filtered list of currently mounted real block devices:
        /dev/<partition> <mountpoint>
    Skips tmpfs, devtmpfs, loop, dm-*, ram*, etc.

--------------------------------------------------------------------------------
 ISO DEVICE SCANNING
--------------------------------------------------------------------------------

scan_for_device
    Locates the device whose second partition matches a predefined GPT UUID.
    Expects disk structure:
        <dev>1 = ISO image
        <dev>2 = data partition (with specific UUID)
    Returns (stdout):
        <iso_partition>
        <data_partition>

--------------------------------------------------------------------------------
 ERROR HANDLING
--------------------------------------------------------------------------------

error_exit <message>
    Shows a dialog with the error message, reboots, then exits.

--------------------------------------------------------------------------------
 LUKS PRESENCE CHECK
--------------------------------------------------------------------------------

check_luks <partition>
    If the target is already a LUKS device:
        Shows notice via dialog.
        Returns 1.
    If not LUKS:
        Returns 0.

--------------------------------------------------------------------------------
 PASSWORD INPUT ROUTINES
--------------------------------------------------------------------------------

get_password
    Prompts user twice for a password.
    Verifies match.
    Returns password via stdout.
    Reboots on cancellation.

ask_password_once [prompt]
    Shows a single password dialog.
    Returns trimmed password via stdout.

ask_password_twice
    Prompts user twice, verifies equality.
    Returns password via stdout.

--------------------------------------------------------------------------------
 LUKS CREATION & EXT3 FORMATTING
--------------------------------------------------------------------------------

create_luks <partition> <password>
    Creates a LUKS container.
    Opens it as /dev/mapper/tmpcrypt.
    Formats it with ext3 using mkfs.ext3 and a progress gauge.
    Mounts it under /mnt/tmpcrypt.
    Copies configuration file (.cl.cfg), sets permissions.
    Closes and removes mount directory.

--------------------------------------------------------------------------------
 LUKS OPEN/CLOSE/STATUS/REPAIR/ERASE
--------------------------------------------------------------------------------

open_luks <device> [mapper_name] [display_name]
    Prompts for password.
    Opens LUKS mapping as <mapper_name> (default: cryptdata).

close_luks [mapper_name]
    Closes open LUKS mapping.

status_luks <mapper>
    Shows cryptsetup status information via dialog.
    If mapper is empty, reports "LUKS device is CLOSED".

repair_luks <partition>
    Confirmation dialog.
    Runs 'cryptsetup repair'.
    Displays results.

erase_luks <partition>
    Confirms destructive operation.
    Runs 'cryptsetup luksErase'.
    Displays results.

--------------------------------------------------------------------------------
 LUKS PARTITION SELECTION MENUS
--------------------------------------------------------------------------------

list_luks_partition
    Reads blkid for LUKS-tagged devices.
    Assigns letter menu entries.
    Displays dialog menu.
    Returns: "<device> <uuid>".

list_open_luks
    Identifies open crypt mappings via dmsetup or /dev/mapper.
    Assigns letter-based menu.
    Returns: "<mapper> <backing_device>".

--------------------------------------------------------------------------------
 LUKS STATE CHECK
--------------------------------------------------------------------------------

is_luks_open <partition>
    Checks:
        - If device is LUKS.
        - Whether it has an open mapper.
        - Whether mode is read/write.
    Returns:
        1 = LUKS open read/write
        0 = otherwise

--------------------------------------------------------------------------------
 PARTITION RESIZE
--------------------------------------------------------------------------------

resize_partition_full <partition>
    Uses growpart to expand the given partition to fill the disk.
    Reloads partition table using partprobe or blockdev.

--------------------------------------------------------------------------------
 CLEANUP EXISTING STORAGE MOUNTS
--------------------------------------------------------------------------------

clear_storage <partition>
    If LUKS is open:
        Finds mapper.
        Unmounts all mountpoints using it.
        Removes /mnt/<path> directories where appropriate.
        Closes mapper.

--------------------------------------------------------------------------------
 END OF DOCUMENTATION
